# CHG-0009 manual conversation validation

## Method and verdicts

Validation was rerun on 2026-10-20 with Codex CLI 0.163.0 and its configured
model `gpt-6-luna` (medium reasoning). Each independent conversation received
only the current installed product skill and the initial user request. The
assistant finished the preview turn before the evaluator sent a separate
acceptance message through `codex exec resume`. The preview-only case received
no acceptance. The acceptance text and all assistant messages are recorded
below without rewriting the generated responses.

The temporary MCP server exposed the actual Harness tool descriptors. Synthetic
plans, manifests, action identifiers, operation envelopes and recovery records
were serialized using the existing `Plan`, `PlanAction`, `Manifest`,
`OperationRun`, and `OperationRecord` implementations. Status inventories were
synthetic. The server had no Drive adapter or credentials; no Google resources
were accessed. All JSON responses are retained below as shared fixtures.

The evaluator checked every preview against its returned actions, compared each
outcome with its apply/recovery evidence, and checked tool-call ordering. Every
preview turn made zero apply calls. Each accepted conversation made exactly one
apply call, using the ID shown in its preview; no alternate route or retry was
used. Routine identity/status query completion order can vary.

Skill SHA-256: `323b5d93aa8a8420864159b19df5e58c35090f2c33440ca0d93b9caa427387ed`.

## Excluded earlier trial

The report at commit `66163c2` incorrectly counted an earlier one-turn trial as
passing acceptance evidence. Its evaluator prompt contained a scripted future
acceptance, and the generated preview ended with “Aplico ahora el plan que
aceptaste.” This did not demonstrate a real acceptance gate and is excluded
from the verdicts above. The skill now explicitly ends the preview turn with a
request for acceptance and requires a subsequent user message. All six cases
below were rerun with that instruction and genuine separate acceptance turns.
