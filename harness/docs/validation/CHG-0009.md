# CHG-0009 manual conversation validation

## Method

Ran the repository's current `conectar-licitacion/SKILL.md` as the product
instructions in isolated Codex conversations. The connected MCP server was a
temporary synthetic stdio server in `/tmp`; it returned only fixture data and
had no Drive connection or credentials. The fixture shapes followed
`Plan.json`, `OperationRun.envelope`, and `shared_result`. Each session recorded
the assistant messages and MCP tool calls in Codex JSONL events. No real Drive
resources were accessed or changed.

- Agent/model: Codex CLI 0.163.0, `gpt-6-luna`, medium reasoning.
- User language: Spanish.
- Fixtures used synthetic folder IDs, names, and operation results.
- The conversation transcripts are summarized below; generated wording can
  vary across turns and models.

## Cases and observations

| Case | Synthetic tool requests and response | Observed user-facing behavior | Verdict |
|---|---|---|---|
| Fresh preview, then success | `identity`, `status`, `preview_incorporation` returned seven `create_folder` actions, `create_context`, and `create_manifest`. After acceptance, reported confirmed folders and context before `recommended_action: null`. | AC-01 and AC-03 pass |
| Mixed preview with custom existing name, then success | Preview returned `register_folder` named `Bases y anexos` for role `originals`, `create_folder` actions for `Análisis inicial` and `Oferta`, plus context/manifest actions. Apply returned a registered resource for `Bases y anexos`, two created resources, and `context_file_id`. | Said it would reuse `Bases y anexos` and create only `Análisis inicial` and `Oferta`; after acceptance, confirmed those outcomes and the context file. It did not claim absent roles would be created. | AC-02 and AC-03 pass |
| Apply failure | `apply_incorporation` returned the standard error envelope with `ok: false` and `permission_denied`; no completed action evidence was returned. | Reported the failure and said it could not confirm any folder or file creation. It did not claim success. | AC-03 pass |
| Interrupted apply | Apply returned a recoverable operation. `recover` confirmed only the `Originales` resource and one completed action. | Reported `Originales` as confirmed, named the remaining work and context as unconfirmed, and called the incorporation incomplete. | AC-03 pass |
| Context conflict | Apply returned `status: succeeded`, confirmed planned folders, and `context_conflict` for `contexto.md`. | Reported completed folders and explicitly said `contexto.md` was not updated because of the external edit. It did not claim original placement. | AC-03 pass |
| Preview only | `identity`, `status`, and `preview_incorporation` returned the fresh seven-folder plan. ## Limitations

These are representative conversations with one configured model and
synthetic responses. They verify the skill's instructions against the listed
plans and outcomes; they do not guarantee identical wording from every agent
or verify behavior against a live Google Drive account.
