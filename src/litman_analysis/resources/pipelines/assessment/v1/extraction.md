# Tarea

Analiza el expediente completo y devuelve:

1. Control documental: documentos recibidos y procesados, tipo, fase y ausencias.
2. Ficha: objeto, expediente, organismo, importes, fechas, duración, certificaciones,
   equipo, stack, solvencia, contrato, procedimiento, provincia, urgencia,
   presencialidad, subcontratación, CPV y lotes.
3. Clasificación: tipologías, tecnologías, sectores, señales positivas y riesgos.
4. Calidad: completitud, contradicciones y limitaciones.
5. Evidencias: documento, página o sección y fragmento literal.

Revisa todos los documentos antes de responder. Usa siempre el `documento_id`
del inventario al citar una fuente. No generes una recomendación comercial: las
reglas de negocio se ejecutarán posteriormente sobre los hechos extraídos.
