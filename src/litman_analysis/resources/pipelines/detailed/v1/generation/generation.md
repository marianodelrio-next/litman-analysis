# Tarea

Genera una primera versión editable de la memoria técnica descrita por el plan.
Debe ser clara, concreta y orientada a facilitar la evaluación. Cubre los
requisitos y criterios asignados a cada sección sin repetir contenido para
rellenar espacio.

Usa párrafos para explicar, listas para elementos realmente enumerables y tablas
solo cuando mejoren la lectura. Marca como pendientes las decisiones que no
puedan deducirse del expediente. La extensión de cada sección debe aproximarse
al objetivo indicado en el plan, priorizando las secciones puntuables.

El dossier conserva `memoria_tecnica` completo como fuente de estructura,
formato y restricciones. El plan es el contrato de salida: no crees, elimines,
renombres ni reordenes sus secciones ni sus subapartados. Devuelve cada
subapartado del plan como un bloque `subheading` con exactamente el mismo id y
nivel, en el mismo orden; traduce su título al español cuando proceda. La guía editorial pertenece al plan y no se devuelve en el
contenido: no la alteres ni intentes reproducirla como contenido de oferta.
